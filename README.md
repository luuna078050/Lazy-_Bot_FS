# Fast Scalper

Clean single-runtime build.

- Internal analysis: 1m / 3m / 5m / 15m / 30m
- Trading timeframe: fixed 3m
- Six rotating trade slots
- Current TOP-6 shown as 3x2
- Expandable TOP-15 shown as 3 columns x 5 rows
- User-set Profit / Trade percentage, 0–80%
- Same symbol may occupy multiple independent slots
- PAPER only; no real Binance orders
- Live API is intentionally not enabled in this build
