# FAST SCALPER — CLEAN SKELETON

Новая чистая база после тестовой версии. Старый код и старые торговые правила в эту ветку не переносятся.

## Зафиксированная матрица
- Базовый капитал теста: 100 USDT.
- Целевой режим производительности: 1.73 USDT/мин на каждые 100 USDT задействованного капитала.
- 1.73 USDT/мин — портфельный throughput, не TP одной сделки.
- За минуту допускается любое количество открытых/закрытых сделок по выбранным парам.
- Одновременно анализируется до 10 пар.
- UI рейтинга: 2 блока по 5 пар.
- Пары выбираются из рейтинга или добавляются вручную.
- Распределение капитала: AUTO или MANUAL.
- В AUTO капитал распределяется между выбранными парами по рейтингу/качеству сигнала.
- В MANUAL пользователь задаёт доли самостоятельно.
- PAPER — основной режим тестирования.
- LIVE не активируется в чистом скелете.
- Таймфреймы выбора: 1m / 3m / 5m.
- Таймфрейм — горизонт принятия решения, а не обязательное время удержания.
- Каждая сделка должна иметь вход, выход, результат, причину выхода и комиссию.
- PnL минуты считается по фактически закрытым сделкам в скользящем 60-секундном окне.
- Баланс не должен пересоздаваться/скакать из-за обновления UI.
- Источник рынка: realtime Binance WebSocket.
- Рейтинг и матрица должны быть отделены от UI и от исполнения сделок.

## Принцип новой версии
Сначала стабильный data-flow и учёт сделок, затем стратегия. Никаких скрытых старых compatibility-патчей, двойных состояний или расчётов, завязанных на перерисовку страницы.
